# 00067 的博客

个人博客，基于 [Hexo](https://hexo.io/) 构建，部署在 GitHub Pages。

## 地址

<https://jiangoduck.github.io>

## 本地开发

```bash
# 安装依赖
npm install

# 启动本地服务器
hexo server

# 生成静态文件
hexo generate

# 部署到 GitHub Pages
hexo deploy
```

## 目录结构

- `source/` - 文章源文件
- `themes/` - 主题文件
- `public/` - 生成的静态文件（部署用）

## 技术栈

- [Hexo](https://hexo.io/) - 静态博客框架
- GitHub Pages - 托管部署
